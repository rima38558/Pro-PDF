Roadmap
=======

Short-term (next milestones)
- Stabilize backend tests and CI (done).
- Implement core PDF tools: merge, split, rotate, watermark (basic implementations present).
- Finish auth flows, email verification, password reset, and subscription model (in progress).

Medium-term
- Implement conversion tools (Office ↔ PDF, HTML ↔ PDF), OCR and compression.
- Add PayU India integration for payments and webhooks.
- Build admin dashboard and invoicing PDF generation.

Long-term
- Advanced image tools and background removal.
- PDF Highlighter (Excel-driven) as premium feature.
- SaaS readiness: monitoring, autoscaling, and paid onboarding flows.

How to contribute to the roadmap
- Open issues with clear requirements and link to designs or mockups.
- Prioritize tasks with impact on user flows (upload → process → download).
